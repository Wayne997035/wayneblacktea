# Definition of Done

WBT 3.0 is done when it behaves like the first practical software-level step toward the E.V. north star.

Not when:
- it has a nice orb
- it has voice
- it has a camera
- it has more MCP tools

But when these form one coherent loop:

```text
Perceive
→ understand current state
→ recall personal context
→ reason
→ seek missing evidence
→ act within authority
→ verify
→ record outcome
→ improve future context
```

## Final requirements

- direct native WBT conversation
- realtime voice
- visual/screen perception
- active perception
- Runtime
- Context Compiler
- provider-independent model runtime
- Capability/Policy
- Event/World/Attention
- Persistent Operators
- trace/observability
- proposal-gated durable learning
- new Web collaboration IA
- deterministic evals
- privacy defaults
- explicit degraded modes
- Go + TypeScript core boundary preserved

## Product identity test

A user should feel:

> "WBT is a capable partner I work with."

not:

> "WBT is a database UI."

and not:

> "WBT is simulating a relationship instead of helping me work."
