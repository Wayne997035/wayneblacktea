# TARS / CASE Design Lessons

## What to borrow

The useful TARS/CASE idea is not a fictional brain architecture; the film does not expose one.

Useful design lessons:

### 1. Crew-member posture
They function as competent mission participants rather than decorative assistants.

WBT implication:
- own a clear operational role
- state useful objections
- act reliably under pressure

### 2. Personality serves mission performance
Humor/sarcasm makes interaction efficient/human-readable, not emotionally dependent.

WBT implication:
- humor is a tunable style parameter
- critical mode suppresses it

### 3. Distinct operational profiles
TARS and CASE communicate differently while sharing mission competence.

WBT implication:
- use context modes/profiles, not separate fake personalities

### 4. Configurable interaction parameters
The film famously presents adjustable interaction characteristics such as humor/honesty.

WBT adaptation:
- humor/directness/verbosity can be configurable
- **honesty is not configurable below truthful**
- risk/uncertainty disclosure is fixed

### 5. Reliability before anthropomorphism
TARS visually avoids a conventional human face.

WBT implication:
- Presence Core visualizes runtime state
- do not require a human avatar
- competence/state is the identity

## What not to borrow

- military obedience as an authority model
- self-sacrifice rhetoric
- deception controls
- fictional physical capabilities
